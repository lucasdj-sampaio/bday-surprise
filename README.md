# 🎁 Bday Surprise

A romantic and gamified way to celebrate a special date — through surprises, clues, and a magical treasure‑hunt experience. ✨💖🗺️

## 🌟 Essence of the Project

This project turns a meaningful date into an unforgettable adventure. Instead of giving a simple gift, you create a **journey filled with hints, secret messages, and emotional discoveries**.

It is designed to:

* 💌 Deliver surprise gifts in a fun, mysterious way
* 🗺️ Reveal clues step by step, like a treasure hunt
* 🎮 Add light gamification to make the experience memorable
* ❤️ Build emotional connection through interactive storytelling

## 🚀 Tech Overview

* **Frontend:** React
* **CMS:** Strapi (public GET, protected content, and a special custom route for the game mechanics)
* **Purpose:** Simple, clean, and lightweight — no backend server needed beyond Strapi

## 💖 Why this exists

Because giving a gift is nice…
But crafting an *experience* is unforgettable. ✨

Let this project help you turn love into an adventure. 💕🎁
